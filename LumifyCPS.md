## (An LLM told me): 10 Things You Can Do in Copilot Studio That You Can't Do in Agent Builder

1. **Publish to external channels**
   - Deploy agents to websites, Teams, mobile apps, and other supported channels.
   - Agent Builder agents are intended primarily for Microsoft 365 Copilot.

2. **Create custom topics**
   - Define conversation topics with trigger phrases, branching, and custom responses.
   - Agent Builder does not provide full topic authoring.

3. **Build multi-step workflows**
   - Create guided business processes and orchestrated workflows.
   - Agent Builder focuses on declarative, knowledge-driven interactions.

4. **Invoke Power Automate flows**
   - Trigger cloud flows directly from conversations.
   - Not available in Agent Builder.

5. **Use Power Platform connectors**
   - Connect to hundreds of Microsoft and third-party services.
   - Agent Builder does not support connector-based actions.

6. **Call external APIs**
   - Create actions that invoke REST APIs and external systems.
   - Agent Builder cannot author actions that integrate external services.

7. **Manage conversation variables**
   - Capture, store, and reuse user inputs throughout a conversation.
   - Agent Builder provides a much simpler interaction model.

8. **Implement complex conversation logic**
   - Use conditions, branching, loops, and decision trees.
   - Agent Builder relies more heavily on LLM-driven reasoning.

9. **Integrate with Dataverse**
   - Read and write business data stored in Dataverse.
   - Agent Builder is not designed around Dataverse integration.

10. **Support enterprise-grade agent development**
    - Enable advanced testing, lifecycle management, multi-channel deployment, and business process automation.
    - Agent Builder is intended for rapid creation of Microsoft 365 Copilot declarative agents.

### Summary

**Copilot Studio**
