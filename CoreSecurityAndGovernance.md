## Copilot Studio Core Security & Governance Features

### **Data Loss Prevention (DLP)**
Enforce environment-level or tenant-level data policies to control which knowledge sources (such as SharePoint sites or public websites) makers can connect to.

### **Authentication Controls**
Support flexible bot authentication options—including **No authentication** for public data, **Microsoft Entra ID** integration, and manual **OAuth 2.0** configuration—to ensure responses respect user permissions.

### **Encryption & Data Residency**
Protect data at rest and in transit using service-side encryption, with options to enable **Customer-Managed Keys (CMK)** for enhanced cryptographic control.

### **Threat Detection**
Mitigate prompt injection risks with built-in runtime defenses, alongside options to configure external threat detection systems.

### **Compliance & Auditing**
Track activity via the **Microsoft Purview** portal, utilizing audit logs, sensitivity labels, and connector governance to prevent oversharing.

### **No Model Training**
Customer data and prompts are **not** used to train or improve foundational Microsoft AI models.
